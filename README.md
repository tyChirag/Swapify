#Swapify
## 📌 Overview
This project is a peer-to-peer trading platform where users can exchange items they no longer need. Users can list products, specify what they want in return, and connect with others for direct swaps or sales. The platform combines the concept of barter with modern online marketplaces.

---

## 🚀 Features
- User profiles with listings and wishlist  
- Add items with images, descriptions, and categories  
- Option to exchange items or sell them  
- Smart matching between users with mutual needs  
- Chat system for negotiation  
- Location-based discovery  
- Ratings and basic trust system  

---

## 🧠 Concept
The platform is inspired by the barter system, allowing users to trade goods directly without always using money, while also supporting traditional buying/selling for flexibility.
